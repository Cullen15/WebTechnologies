## AI Reflection

### Using Generative AI
I used ChatGPT to help recreate this assignment and get a working structure for the choose your own adventure. It helped me quickly understand how to organize the story and connect buttons to JavaScript functions that update the page.

### What I liked
I liked how fast AI helped me get a base version working. It was useful for reminding me what requirements I needed to hit and for showing examples of how to update the DOM with JavaScript.

### What I didn’t like
Some of the AI generated code felt longer and more complicated than it needed to be. I had to simplify it and rewrite parts so it made sense to me and matched my own story and interests.

### Successes
I successfully built a single page adventure that updates text, images, and choices using JavaScript. Each choice changes what happens next, and I was able to connect JavaScript, HTML, and CSS together without reloading the page.

### Challenges and how I overcame them
The hardest part was keeping track of the different story paths. I solved this by using a `scene` variable and a single render function to control what shows on the page. Once that was working adding new choices was much easier.

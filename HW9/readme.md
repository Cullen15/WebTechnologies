# Reflection

## Gen AI Usage Reflection

Whenever I code I try to use AI as a tool, but not let it just do everything for me. I mainly use AI to help me get started or figure out the basic structure, especially when we are working with something new like jQuery animations. From there I go through the code myself, make changes, and try to understand what everything is doing and why it works.

For this project AI helped me organize things like the arrays, timers, and animations that make the images, text, and shapes change over time. After that I adjusted the layout, picked my own images, changed the styling, and made sure everything worked the way I wanted it to. 

I think AI is a really useful tool and it is only going to get better. Learning how to use it the right way, while still understanding the code, will be really important if I want to be successful in the future.

## Other People / External Sources Usage

I watched a few YouTube videos while working on this project because I am a visual learner. Seeing the code being used in real time helped me understand how jQuery animations actually work instead of just reading about them. It helped me grasp how things like arrays, timers, and movement come together to make elements change on the screen.

The videos helped me better understand how the code works and why it works, which made it easier for me to make my own changes and build something that met the requirements of the assignment.

## Homework Reflection

For this assignment I created a simple web page that connects a
JavaScript file and logs information to the browser console. I used
console.log() to list my favorite websites, games, and artists, and I added
a basic prompt() interaction to collect user input.

Comparing my work to what a generative AI could create, I noticed that
AI can generate functional code very quickly. But writing and reviewing
the code myself helped me understand how JavaScript files connect to
HTML and how console logging works.

If I relied only on AI-generated code or someone else’s work, I would
complete assignments faster, but I wouldn’t fully understand what the code
is doing. I feel confident explaining this code because it is simple and I
understand each part of it.

The final work still feels like my own because I chose the content,
understand the structure, and can explain how everything functions.

When I’m building a coding website, I like to use AI to create a baseline that I can build off of. It saves a lot of time and acts like a template to get started. When I tried having AI create the entire assignment from scratch, it didn’t really work. AI is really good at helping figure out problems in your code or giving you ideas when you get stuck. But when you give it something too large or open-ended, it can struggle to make everything work correctly.
